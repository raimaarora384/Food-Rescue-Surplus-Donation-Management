# Food-Rescue-Surplus-Donation-Management
A C-based Data Structures project for managing surplus food donations and donation records.


## 🎯 Problem
Food wastage is a major issue when surplus food is not efficiently collected and distributed to people or organizations in need.

This project provides a simple console-based system to manage surplus food, register NGOs, search available food, and allocate donations.

---

## 🎯 Objectives

- Manage surplus food donation records
- Register and maintain NGO information
- Search for available food
- Allocate donations to NGOs
- Maintain donation history
- Track the total number of meals
- Identify the highest-priority food donation

---

## ⚙️ How It Works

The system provides a menu-driven interface through which users can:

1. Add food donation details.
2. Display available food.
3. Search for food.
4. Register an NGO.
5. Display registered NGOs.
6. Allocate a donation.
7. View donation history.
8. Calculate total meals.
9. Find the highest-priority food.
10. Exit the program.

---
